- **검증용 페이지·주소**: `tests/holidays.html` 에서 공휴일 표·주말·휴원일 판별을 눈으로 검사할 수 있고, `living.html?debug=1` 은 창에 `__livingDebug`(오늘 날짜·쉬는 날·체크리스트)를 열어 주며 `living.html?debug=1&now=2026-11-21T08:00:20` 처럼 시계를 옮겨 알람이 울리는지/안 울리는지 확인할 수 있습니다(일반 주소에서는 전혀 동작하지 않음).
- **등원 집중 모드**: 평일 07:30~08:55(평일 기본 출발 08:40 + 15분, 오늘 출발 시각을 더 늦게 잡았으면 그 15분 뒤까지)에 `index.html`을 열면 자동으로 `living.html`로 이동합니다. ⚙️에서 끌 수 있고, 거실 보드의 `🏠 전체 모아보드` 버튼으로 들어오면 그 세션은 모아보드에 머뭅니다.
- **전체 모아보드 잠금**: 상단 `🏠 전체 모아보드` 버튼은 **짧게 눌러도 이동하지 않습니다**(아이 오터치 방지). 어른이 **2초 이상 길게 누르면** 모아보드로 넘어가고, 짧게 누르면 "어른용: 2초 길게 누르면 전체 보드로 이동해요" 안내만 2.4초 띄웁니다. 길게 누르는 동안 버튼 아래에 흰색 진행 막대가 차오릅니다.
- **앱처럼 설치(PWA)**: `manifest-living.json` · `sw.js` · 앱 아이콘(`assets/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`)이 들어 있어 안드로이드 크롬에서 **주소창·탭 없는 전체화면 앱**으로 설치됩니다. 서비스 워커는 `living.html`·`assets/living.*`·`assets/kr-holidays.js`·`data/board-data.json` 을 **항상 네트워크 우선**으로 받아 오므로 아침 브리핑 갱신이 캐시에 가려지지 않고, 그림·아이콘만 캐시해 인터넷이 끊겨도 마지막 화면이 뜨니다.

### 태블릿에 앱으로 설치하기 (안드로이드)

1. 태블릿 크롬에서 https://circle170115-star.github.io/family-board/living.html 을 엽니다.
2. 오른쪽 위 `⋮` → **앱 설치**(또는 **홈 화면에 추가**)를 누릅니다. `앱 설치`가 안 보이면 한 번 더 새로고침한 뒤 다시 시도합니다.
3. 홈 화면의 **등원 보드** 아이콘으로 열면 주소창·탭 없는 전체화면으로 빠집니다(세로·가로 모두 OK).
4. 태블릿 설정에서 크롬을 **고정 화면(앱 고정)** 으로 두면 아이가 다른 앱으로 나가는 것도 막을 수 있습니다.

## 데이터 업데이트 방법

모든 내용은 **`data/board-data.json` 한 곳**에 있습니다. 이 파일만 고치면 화면에 바로 반영됩니다.

```json
{
  "schedules": [ ... 아이별 주간 일정 (요일·시간·차시 규칙) ... ],
  "meals": { "2026-11-17": { "menu": [...], "calories": "..." } },   ← 급식 (NEIS에서 자동 최신화도 함)
  "kindergartenEvents": [ ... 유치원 가정통신문 일정 ... ],
  "kindergartenSnacks": { "2026-11-17": ["인절미", "믹스베리씨"] },   ← 방과후 간식
  "eveningRoutine": { "anchor": "2026-11-17", "step": 2, "time": "20:00", "weekdaysOnly": true, "target": "both", "subjects": [ { "emoji": "🎨", "name": "미술" }, ... ] },   ← 평일 격일 저녁 홈활동 규칙(5과목)
  "weather": { ... 날씨 스냅샷 (폴백용) ... },
  "growth": [ { "child": "daeun", "records": [ { "date": "2026-11-17", "height": 121, "weight": 22 } ] } ],
  "holidays": { "2026-12-25": { "name": "성탄절", "type": "공휴일" }, ... },
  "readingPoster": { "date": "2026-11-21", "proverb": { "badge": "오늘의 속담 1", "title": "백지장도 맞들면 낫다", "subtitle": "...", "summary": "...", "panels": [ { "num": 1, "speech": "으쌰… 무거워!", "caption": "혼자서는 낑낑", "image": "assets/reading/panel1-crop.png" }, ... 4컷 ], "meaning": "...", "promise": "..." }, "word": { "badge": "오늘의 영단어 1", "word": "share", "meaning": "함께 나누다 · 공유하다", "audio": "assets/reading/audio/share.mp3", "bannerImage": "assets/reading/word-banner.png", "examples": [ { "num": 1, "en": "Let's share.", "ko": "함께 나누자.", "highlight": ["share"], "audio": "assets/reading/audio/share-ex1.mp3" }, ... 3개 ], "tip": "..." } }   ← 📖 오늘의 읽을거리 (속담·영단어 2탭)
}
```

- 📖 **읽을거리 교체는 `readingPoster` 만 고치면 됩니다.** 오늘의 속담은 `proverb` 안의 `title`·`subtitle`·`summary`·`panels`(4컷: `speech` 말풍선, `caption` 컷 설명, `image` 그림)·`meaning`·`promise` 를, 오늘의 영단어는 `word` 안의 `word`·`meaning`·`bannerImage`·`examples`(3개: `en`·`ko`·`audio`·`highlight` 낱말)·`tip` 을 바꿉니다. 그림은 `assets/reading/` 에, 발음 MP3 는 `assets/reading/audio/` 에 넣고 경로를 적으면 그대로 재생됩니다(`audio` 를 비워도 Web Speech `en-US` 로 읽어 줍니다). 각 탭 본문의 **🎬 영상으로 듣기** 버튼은 그 탭 자리에서 영상을 재생하고 끝나면 그림 화면으로 돌아옵니다 — 영단어 영상의 한국어 설명은 `word.koIntroAudio`·`koIntroText`, `examples[].koAudio`·`koScript`, `koTipAudio`·`koTipText` 에 넣으면 되고(비우면 화면 글자로 대신 읽어 줍니다), 속담 영상은 `panels[].audio` 와 `meaningAudio` 를 씁니다. `proverb`·`word` 를 모두 비우면 "오늘의 읽을거리를 준비하고 있어요" 안내 카드가 뜨고, 예전처럼 **한 장짜리 포스터 PNG** 를 쓰고 싶으면 `readingPoster.image` 에 경로를 넣으면 그 그림이 그대로 뜹니다(없는 파일을 찾던 404 는 없앴습니다).

- 매일 아침 브리핑(06:00)에서는 이 파일의 `meals`·`weather`·`meta.updatedAt`를 그날 값으로 갱신해 커밋하면 됩니다. 클라이언트는 열 때마다 NEIS(당월 급식)와 Open-Meteo(날씨)를 실시간으로 조회하고, **실패하면 이 파일의 스냅샷으로 폴백**합니다.
- 공휴일이 바뀌거나 임시공휴일이 지정되면 `holidays`에 한 줄만 추가하면 일정·차시 계산이 전부 자동으로 다시 반영됩니다.

## 기술

- 일러스트: `assets/illustrations/` — `{daeun,seungmin}-avatar.png`(아이 캐릭터)와 `tile-*.png`(루틴 타일, 저녁 홈활동 5과목 포함) 모두 **배경 투명 PNG**, 파스텔 플랫 2D 동화풍으로 통일. 같은 이름으로 파일을 바꿔 넣으면 화면에 그대로 반영됩니다.
- 읽을거리 자산: `assets/reading/` — `panel1~4-crop.png`(속담 4컷), `word-banner.png`(영단어 그림), `ico/*.png`(배지·불빛·새싹 등 작은 아이콘), `audio/*.mp3`(원어민 발음 — 예문 파일명은 `{word}-ex1~3.mp3` 처럼 단어명을 넣어 매일 고유하게 하고, `sw.js` 는 이 MP3 를 **네트워크 우선**으로 받아 옵니다). 속담·영단어 화면은 시안과 같은 **주아(Jua)체**를 `assets/fonts/Jua-Regular.ttf` 로 직접 올려 씁니다(외부 CDN 없음, 첫 로드 뒤 서비스 워커가 캐시).
- 정적 사이트(HTML/CSS/JS) + Pretendard 웹폰트, GitHub Pages 호스팅
- **수학 문제는 한 곳에서**: `assets/math-engine.js`(`window.FamilyMathEngine`)의 `LEVEL_CONFIG` 한 곳만 고치면 모아보드(`assets/app.js`)와 거실 보드(`assets/living.js`)가 동시에 바뀝니다. 단계를 올릴 때도 이 파일만 수정하면 됩니다(스크립트는 app.js·living.js보다 먼저 불러옵니다).
