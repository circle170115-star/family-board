# 우리 집 모아보드 🏠

다은이(7세)·승민이(5세)의 **일정 · 급식 · 날씨 · 성장 기록 · 수학 놀이터**를 한 화면에 모은 가족용 웹 대시보드입니다.

**주소**: https://circle170115-star.github.io/family-board/

## 🏠 거실 등원 보드 (`living.html`)

아이들이 거실 태블릿/모니터에서 **직접 눌러** 아침 등원 준비를 끝내는 화면입니다.
**주소**: https://circle170115-star.github.io/family-board/living.html · 모아보드 상단 `🏠 거실 등원 보드` 버튼으로도 이동

- **상단 헤더**: 실시간 시계 · 오늘 날짜/요일 · 우장산동 날씨/기온/등원 옷차림 한 줄 · 오늘 유치원 소식(등원시간 조정·도서대여·급식 메인 메뉴·간식·미세먼지) · `🏠 전체 모아보드` 링크
- **➕ 더하기 놀이**: 헤더의 노란색 `➕ 더하기 놀이` 버튼(좁은 화면에서는 ➕만)을 **한 번 누르면** 거실 화면 전체에 모아보드 `수학 놀이터`와 같은 덧셈 놀이가 열립니다. `승민 (5세 · 한 자리 덧셈)` / `다은 (7세 · 두 자리 덧셈·뺄셈)` 탭, 보기 4개 중 정답 고르기, 맞히면 1.1초·틀리면 1.9초 뒤 다음 문제, 맞힌 문제/시도 수와 연속 정답 표시, `✕ 그만하기`로 보드 복귀. 놀이는 보드 데이터를 못 불러와도 열리고, ⚙️ 효과음 설정을 그대로 따르며, 등원 알람 배너는 놀이 화면 위에 항상 뜨니다.
- **출발까지 남은 시간 프로그레스 바**: 평일 기본 출발 08:40(준비 시작 07:30 기준). 가정통신문에 `등원 시간 10시부터로 조정` 같은 내용이 있으면 **등원 15분 전 출발**로 자동 계산(예: 수능일 09:45). 20분 이내 주황, 10분 이내 빨강. (2026-11-20 기본값을 09:00 → 08:40으로 변경, 기기에 예전 기본값 09:00이 저장돼 있으면 한 번만 자동으로 옮깁니다)
- **좌우 2분할 큰 그림 타일**: 다은(7세·열매반) / 승민(5세·새싹반) — 각자 **전용 캐릭터 일러스트 아바타**. 아침 준비 다은 6개(머리 빗기·묶기 포함)·승민 5개, 도서대여 날은 하나 더(목=다은 7개, 화=승민 6개), 🌙 저녁 루틴 8개(손 씻기·가방 정리·오늘의 저녁 홈활동·엘리하이 오늘의 학습·놀이한 거 정리하기·씻기·옷 갈아입기·양치하고 자기). 타일 수에 맞춰 칸 수가 조절됩니다(저녁 8개=4열, 아침 7개=3열). 모든 타일은 이모지 대신 **투명 배경 커스텀 일러스트**(`assets/illustrations/tile-*.png`)로 표시됩니다. 누르면 초록 타일 + `✓ 완료!` 배지.
- **칭찬 스티커**: 한쪽(아침/저녁)을 모두 체크하면 축하 배너·폭죽과 함께 **+1**(하루 한 번, 중복 없음). 10칸 단위 ⭐/💖/🦕 스티커판.
- **저장**: 브라우저 localStorage(`familyLivingBoard.v1`). 날짜가 바뀌면 체크만 초기화되고 누적 스티커는 유지됩니다.
- **⚙️ 부모님 설정**: 오늘/평소 출발 시각(5분 단위·자동), 등원 시간대 자동 전환 ON/OFF·오늘만 끄기, 효과음, 스티커 ±수동 조절, 오늘 체크 초기화, 데이터 다시 불러오기.
- **⏰ 등원 알람(평일 8:00 · 8:20)**: 평일(공휴일·주말 제외) 오전 **8:00**에 맑은 **도-미-솔-도 시작 차임**과 함께 "오전 8시예요! 다은·승민 등원 준비 시작할 시간이에요 · 출발 08:40" 배너, **8:20**(출발 20분 전)에 더 또렷하고 경쾌한 **딩동댕을 두 번 반복하는 경고 차임**과 함께 "출발까지 20분 남았어요 · 08:40 출발" 배너가 상단에 뜨립니다. 두 알람 모두 **하루 한 번**(날짜별로 기록), 헤더 `🔔` 버튼이나 ⚙️ 토글로 함께 끄고 켜며, ⚙️의 `8시 시작음`·`8:20 경고음` 버튼으로 소리를 미리 들어볼 수 있습니다. 브라우저 정책상 첫 터치·클릭 전에는 소리가 막히므로, 화면을 한 번 눌러 두면(또는 테스트 버튼) 이후 알람이 소리와 함께 울립니다. 모든 소리는 외부 오디오 파일 없는 Web Audio 합성음입니다.
- **등원 집중 모드**: 평일 07:30~08:55(평일 기본 출발 08:40 + 15분, 오늘 출발 시각을 더 늦게 잡았으면 그 15분 뒤까지)에 `index.html`을 열면 자동으로 `living.html`로 이동합니다. ⚙️에서 끌 수 있고, 거실 보드의 `🏠 전체 모아보드` 버튼으로 들어오면 그 세션은 모아보드에 머뭅니다.
- **전체 모아보드 잠금**: 상단 `🏠 전체 모아보드` 버튼은 **짧게 눌러도 이동하지 않습니다**(아이 오터치 방지). 어른이 **2초 이상 길게 누르면** 모아보드로 넘어가고, 짧게 누르면 "어른용: 2초 길게 누르면 전체 보드로 이동해요" 안내만 2.4초 띄웁니다. 길게 누르는 동안 버튼 아래에 흰색 진행 막대가 차오릅니다.
- **앱처럼 설치(PWA)**: `manifest-living.json` · `sw.js` · 앱 아이콘(`assets/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`)이 들어 있어 안드로이드 크롬에서 **주소창·탭 없는 전체화면 앱**으로 설치됩니다. 서비스 워커는 `living.html`·`assets/living.*`·`data/board-data.json` 을 **항상 네트워크 우선**으로 받아 오므로 아침 브리핑 갱신이 캐시에 가려지지 않고, 그림·아이콘만 캐시해 인터넷이 끊겨도 마지막 화면이 뜨니다.

### 태블릿에 앱으로 설치하기 (안드로이드)

1. 태블릿 크롬에서 https://circle170115-star.github.io/family-board/living.html 을 엽니다.
2. 오른쪽 위 `⋮` → **앱 설치**(또는 **홈 화면에 추가**)를 누릅니다. `앱 설치`가 안 보이면 한 번 더 새로고침한 뒤 다시 시도합니다.
3. 홈 화면의 **등원 보드** 아이콘으로 열면 주소창·탭 없는 전체화면으로 빠집니다(세로·가로 모두 OK).
4. 태블릿 설정에서 크롬을 **고정 화면(앱 고정)** 으로 두면 아이가 다른 앱으로 나가는 것도 막을 수 있습니다.

## 자동 계산 규칙

- **한국 공휴일 자동 제외**: 공휴일에는 피아노·어퍼룸영어·독서화상·엘리하이화상·유치원 하원 픽업이 **모두 자동으로 쉬어요** ("공휴일 · 수업 없음" 표시). 공휴일 목록은 `data/board-data.json`의 `holidays`에 2026년 11~12월과 2027년 전체(월력요항 기준, 대체공휴일 포함)가 들어 있습니다.
- **어퍼룸영어학원 월 8차시**: 그 달의 **공휴일을 제외한 화·금** 수업일만 순서대로 세어 `1/8차시 ~ 8/8차시` 배지를 붙입니다. 9번째 화·금이 있는 달은 "월 8차시 초과 · 휴강/보강 확인"으로 표시됩니다.
- **엘리하이화상(다은)**: 공휴일을 제외한 수요일 기준 월 4차시 — 홀수 차시 18:10 단독수업, 짝수 차시 18:20 격주수업으로 자동 구분됩니다.
- **엘리하이화상(승민)**: 공휴일을 제외한 화요일 기준 월 4차시 — 2026년 12월까지는 1차시 "엄마-담임선생님 상담", 2~4차시 "승민 단독수업", **2027년 1월부터는 전 차시 "승민 단독수업"**으로 자동 전환됩니다.
- **평일 격일 저녁 홈활동 (다은·승민 공통)**: 기준일 **2026-11-17(화)** 를 0번째로 **평일(월~금)만** 세어, 격일 저녁 **20:00**에 🎨미술 → 📖독서 → 🔢수학 → 🔬과학 → 🎲보드게임 5과목이 차례로 돌아갑니다. 2주(평일 10일)에 한 바퀴 — 11/17 미술 · 11/19 독서 · 11/23 수학 · 11/25 과학 · 11/27 보드게임 · 12/1 다시 미술. **토·일은 세지 않아 주말에는 홈활동이 없고**, 공휴일은 평일 그대로 세므로 리듬이 끊기지 않습니다(공휴일에도 저녁 홈활동은 그대로 표시). 필터(전체·다은·승민) 어느 쪽에서도 함께 보이고, 가족 달력 칸과 주간 시간표 아래 주간 스트립에도 표시됩니다.

## 데이터 업데이트 방법

모든 내용은 **`data/board-data.json` 한 곳**에 있습니다. 이 파일만 고치면 화면에 바로 반영됩니다.

```json
{
  "schedules": [ ... 아이별 주간 일정 (요일·시간·차시 규칙) ... ],
  "meals": { "2026-11-17": { "menu": [...], "calories": "..." } },   ← 급식 (NEIS에서 자동 최신화도 함)
  "kindergartenEvents": [ ... 유치원 가정통신문 일정 ... ],
  "kindergartenSnacks": { "2026-11-17": ["인절미", "믹스베리씨"] },   ← 방과후 간식
  "eveningRoutine": { "anchor": "2026-11-17", "step": 2, "time": "20:00", "weekdaysOnly": true, "target": "both", "subjects": [ { "emoji": "🎨", "name": "미술" }, ... ] },   ← 평일 격일 저녁 홈활동 규칙(5과목)
  "weather": { ... 날씨 스냅샷 (폴백용) ... },
  "growth": [ { "child": "daeun", "records": [ { "date": "2026-11-17", "height": 121, "weight": 22 } ] } ],
  "holidays": { "2026-12-25": { "name": "성탄절", "type": "공휴일" }, ... }
}
```

- 매일 아침 브리핑(06:00)에서는 이 파일의 `meals`·`weather`·`meta.updatedAt`를 그날 값으로 갱신해 커밋하면 됩니다. 클라이언트는 열 때마다 NEIS(당월 급식)와 Open-Meteo(날씨)를 실시간으로 조회하고, **실패하면 이 파일의 스냅샷으로 폴백**합니다.
- 공휴일이 바뀌거나 임시공휴일이 지정되면 `holidays`에 한 줄만 추가하면 일정·차시 계산이 전부 자동으로 다시 반영됩니다.

## 기술

- 일러스트: `assets/illustrations/` — `{daeun,seungmin}-avatar.png`(아이 캐릭터)와 `tile-*.png`(루틴 타일, 저녁 홈활동 5과목 포함) 모두 **배경 투명 PNG**, 파스텔 플랫 2D 동화풍으로 통일. 같은 이름으로 파일을 바꿔 넣으면 화면에 그대로 반영됩니다.
- 정적 사이트(HTML/CSS/JS) + Pretendard 웹폰트, GitHub Pages 호스팅
- 데이터 소스: [NEIS Open API](https://open.neis.go.kr/) (급식), [Open-Meteo](https://open-meteo.com/) (날씨), [AirKorea](https://www.airkorea.or.kr/) (미세먼지)
